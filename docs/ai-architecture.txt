TicketFlow - Traditional Path + AI Path
========================================

Two paths to the same services. Left: deterministic code, right: AI agents.

Protocols
─────────
  MCP    Agent → Tool      "call this function with these params"  (Streamable HTTP)
  A2A    Agent → Agent     "achieve this goal"                     (JSON-RPC 2.0)
  AG-UI  Frontend → Agent  "stream the response"                   (Server-Sent Events)
